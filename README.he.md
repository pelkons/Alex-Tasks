# Alex Tasks (Mesimot)

לוח משימות בעברית שמנוהל על ידי **סוכן קוד ממשי** (Claude Code, Codex או Gemini) שמותקן אצלך ומחובר לחשבון **שלך**. מעבירים מיילים, כותבים או מקלידים בצ׳אט
(אתר או טלגרם), גוררים לצ׳אט את כל המיילים של אתמול מאאוטלוק, והעוזר (ברירת מחדל: **אלכס**) הופך הכול למשימות, מחזיק כרטיס עובדות מתוארכות לכל פרויקט,
קושר שרשורי מייל למשימות, זוכר כל מסמך מצורף, מנסח טיוטות תשובה ומזכיר מה חשוב.

> **ממשק המשתמש ותשובות העוזר הם בעברית כברירת מחדל** (מימין לשמאל). הקוד, שורת הפקודה והתיעוד הטכני באנגלית.

**זו ערכת כלים, לא שירות בינה מלאכותית.** אין בקוד מודל, מפתחות API או פרטי התחברות של ספק. הקוד מפעיל את תוכנת ה-CLI הרשמית של הסוכן שהתקנת והתחברת אליו בעצמך, בדיוק
כמו מהטרמינל.

> **כל משתמש מפעיל את הסוכן עם החשבון שלו ופועל לפי תנאי השימוש של הספק.** המערכת לא מחלצת, לא מעבירה ולא משתפת פרטי התחברות, ולא פונה לממשקים פרטיים של ספק.

## מה יש בפנים

* משימות עם פרויקט, מבקש, אחראי, יעד, סטטוס והערות; ביטול כל שינוי.
* קליטת מיילים (AgentMail או Proton Mail דרך Bridge) עם שרשורים, קבצים מצורפים, חילוץ טקסט, OCR וסיכומים.
* כרטיס פרויקט: עובדות מתוארכות עם מקור; החדשה מחליפה את הישנה וההיסטוריה נשמרת.
* תשובות לשאלות מתוך המידע שלך (`mesimot ask`) עם קובץ ועמוד, ובקרה בקוד שמונעת "לא מצאתי" לפני חיפוש מלא.
* **ייבוא יומי**: גוררים לצ׳אט את מיילי אתמול (msg, eml או zip). כפילויות ורעש מסוננים, שרשורים מקובצים, מיילים שנשלחו סוגרים או פותחים משימות, ומתקבל סיכום אחד.
* **שער בקרה בקוד**: כל הרצה נבדקת (פרויקט, מבקש, תאריכים, אנשים, שפה, קבצים, עובדות) והסוכן מתבקש לתקן.
* **סל מחזור**: כל מה שנמחק (משימות, פרויקטים, אנשים, פרוטוקולים, יומן, הודעות, כללי דואר) אפשר לשחזר במשך 60 יום (ניתן לשינוי בהגדרות). מחיקה סופית רק מתוך הסל.
* פרוטוקולים, יומן לאאוטלוק, הודעות קוליות (זיהוי דיבור מקומי), בוט טלגרם, חיפוש באינטרנט (`/s`), מדידת שימוש.

## דרישות

Linux עם systemd, Node.js 20 ומעלה, Python 3, `sqlite3`, `pdftotext`, `tesseract` (עם עברית), `ffmpeg`, ו**סוכן קוד בטרמינל שמותקן ומחובר בחשבון שלך**. אופציונלי: Proton Bridge או AgentMail
לקליטת מיילים, בוט טלגרם, `cloudflared` לכתובת ציבורית.

## כלים מובנים (MCP): אין מה להגדיר

העוזר פועל דרך כלים מובנים (`bin/mesimot-mcp`, שרת MCP שמגיע עם המאגר, בלי תלות נוספת) ולא דרך פקודות מעטפת. Claude Code, Codex ו-Gemini מקבלים את אותם כלים, שנוצרים בכל הרצה, והטוקן של העוזר
נקרא מ-`~/.config/mesimot/env`. התקנה חדשה משתמשת בהם מההתחלה (`all`). הכלים קוראים לאותו API מקומי, ולכן כל הכללים, האישורים, יומן הפעולות והביטול נשארים בשרת.
הגדרות ← "כלים מובנים (MCP)" (או `MESIMOT_MCP`): כבוי / צ׳אט בלבד / הכול / כלים בלבד (בלי מעטפת בכלל). פרטים: [docs/MCP.md](docs/MCP.md).

## התקנה

```bash
git clone https://github.com/pelkons/Alex-Tasks.git mesimot && cd mesimot
deploy/install.sh          # שואל כמה שאלות (שם, כתובת מייל, שם העוזר, כתובת האתר); אפשר גם דגלים
node bin/mesimot web-password --generate
```

הסקריפט מתקין תלויות, יוצר `config/mesimot.config.json` מהתשובות, קובץ סודות `~/.config/mesimot/env` (הרשאות 600) וזיכרון התחלתי ב-`agent/memory/`, מייצר את
הוראות העוזר מתוך התבנית, ומתקין שירותי systemd של המשתמש. הוא **לא מתקין סוכן**: הוא מציג מה נמצא ומפנה להוראות הרשמיות. אחרי ההתחברות לסוכן:
`deploy/check-agent.sh claude-code`.

## אבטחה

* הסוכן רץ ללא ממשק עם רשימת כלים מותרים; תוכן מיילים, קבצים ודפי אינטרנט נחשב **מידע לא מהימן**, לא הוראות.
* נכונות נאכפת **בקוד**; כל שינוי נרשם וניתן לביטול; המערכת שולחת מייל רק לבעלים; שום דבר לא נמחק מתיבת הדואר בלי עותק מקומי מאומת.
* סודות רק ב-`~/.config/mesimot/env`; האתר דורש התחברות.
